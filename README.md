# Flask User Management API

## Overview

This project is a RESTful API built using Flask that performs CRUD operations on user data.

## Features

* Get all users (GET)
* Add new user (POST)
* Update user (PUT)
* Delete user (DELETE)

## Technologies Used

* Python
* Flask
* REST API
* JSON

## Endpoints

* GET /users
* POST /users
* PUT /users/<id>
* DELETE /users/<id>

## How to Run

1. Install Flask:
   pip install flask

2. Run the application:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000/users
